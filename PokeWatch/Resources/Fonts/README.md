# Fonts

No font files are bundled.

- Pixel lettering (Pokémon Yellow face, speech bubbles, Zzz) uses `PixelFont`, an original 5×7 bitmap
  font defined in `PokeWatch/Components/PixelFont.swift`.
- Every other face uses Apple's system fonts (SF Pro, SF Pro Rounded, SF Mono) through SwiftUI.

This folder stays so a licensed font can be added later; register it under `UIAppFonts` in `project.yml`.
